# JavaScript Learning Projects 🚀

Welcome to my JavaScript Learning Projects repository!

This repository contains beginner-friendly projects that I have developed while learning JavaScript. These projects helped me understand JavaScript fundamentals, DOM manipulation, event handling, and basic logic building.

## 📂 Projects Included

### 1. Colour Changer
- Changes the background colour when a button is clicked.
- Concepts: DOM Manipulation, Event Listeners.

### 2. BMI Calculator
- Calculates Body Mass Index based on height and weight.
- Concepts: JavaScript Functions, DOM Manipulation, Conditional Statements.

### 3. Digital Clock
- Displays the current time and updates every second.
- Concepts: Date Object, `setInterval()`, DOM Manipulation.

### 4. Guess the Number
- A number guessing game where users try to guess a randomly generated number.
- Concepts: Random Numbers, Conditional Statements, Event Handling.

### 5. Keyboard Key Detector
- Detects keyboard key presses and displays the key, key code, and key name.
- Concepts: Keyboard Events, `keydown`, Event Object, DOM Manipulation.

## 🛠️ Technologies Used

## 💻 How to Run the Projects

1. Clone this repository:

   ```bash
   git clone https://github.com/ravi1683/JavaScript-Learning-Projects.git
   ```

2. Open the project folder in Visual Studio Code.

3. Choose any project folder.

4. Open its `index.html` file in your browser.
